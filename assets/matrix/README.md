# 40C3 CDC — Matrix room & space icons

Dark ground #001300, neutral line art #ebedf0, one 40C3 sub-colour per room. Same vocabulary as Pattern0–6 (outlines, square corners, butt caps, miter joins), stroke 5/128 so they hold up at 24–40 px.

## Files
PNG/ — 1024 × 1024, opaque. Element crops room avatars to a circle and space avatars to a rounded square; the artwork keeps clear of both.
SVG/ — same artwork as vectors (128-unit canvas scaled to 1024). CDC_Space_B_wordmark.svg uses the Jersey 10 webfont (text not outlined) — use the PNG, or outline the text in Inkscape/Illustrator with Jersey 10 installed.
