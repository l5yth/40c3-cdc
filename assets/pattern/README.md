# 40C3 Patterns 4–6 — Critical Decentralisation Cluster

Three line-art strips in the style of Pattern0–3, on decentralisation / mesh / peer-to-peer.

- Pattern4.svg — 1a Workbench: crimp tool, RJ45 on a patch cable into a switch, laptop, router, notepad (Σ √), pen, mesh radio, node graph overhead
- Pattern5.svg — 1b Mesh: node graph with every device hanging off a node — radio, phone, laptop, router, Yagi on a mast, notepad, RJ45, dish on a post
- Pattern6.svg — 1c Field day: Yagi mast with guy wires, node box + ground-plane antenna + solar panel, two radios on a coiled cord, RJ45, notepad, dish on a tripod

## Specs
- Tile 380 × 105 units, stroke 1.8 (same weight as Pattern0–3), square corners, outlines only, baseline dashes.
- Tiles horizontally (repeat-x).
- Seam: every tile enters at the left edge and leaves at the right edge through a horizontal graph link at y = 12 (stroke centre), so any sequence of Pattern4/5/6 joins without a kink. Shuffle freely.
- Colour: strokes use currentColor; the root svg has color="#ebedf0" (neutral). Inline the SVG and set CSS color, or edit the attribute.
- PNG/ — 3040 × 840 px (8×) renders on transparent ground in neutral #ebedf0, dark #001300 and green #75b44b, plus a two-tile preview on the dark ground.

## Before print
These are stroked paths; the originals are outlined fills. Illustrator: select all → Object → Path → Outline Stroke. Inkscape: Path → Stroke to Path. Then export with the PSO Coated v3 profile as in the styleguide.
