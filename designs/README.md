# designs

Final designs for web, slides, shirts and other uses.

1. Create a folder named after the section, for example `designs/shirts/`.
2. Put the files in it.
3. Run `npm run build`.

Each folder becomes a section on the page. Images get a preview and a copy-paste snippet. Other files get a download link.
